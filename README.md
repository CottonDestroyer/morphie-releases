An SCP:RP morph maker/storage, making morphing much more convenient.

## Locker

<img width="1442" height="932" alt="image" src="https://github.com/user-attachments/assets/fcb8e797-7933-49a2-9f47-2e19f44c1538" />

### Features:
- Morph preview
- Interactively add/remove accessories/clothing
- Supports built-in SCP:RP gear
- Edit skin colour/size
- Edit Ntag/Rtag
- permanent/temporary commands
